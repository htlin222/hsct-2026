
## 4. 版面觀察(實際驗證過的)

- **答案的藏法每年不同,「行尾是單一大寫字母」在任何一年都靠不住**:
  - 108/110:答案是 **紅色(#ff0000)粗體** `(X)` span。多數跟題號同列;108 有 2 題、110 有 9 題印在下一列的左欄(x 在題號欄與題幹欄之間),110-42 的 `(A)` 甚至自成一列、整列沒有其他字 —— 用「紅色 span」這個訊號就不必管位置。
  - 109:粗體單字母,但多半跟題幹黏在同一個 span(`'C   Select the …'`),只能用文字規則(題號後第一個單獨字母)。
  - 111–113:最右欄 x≈537 的黑色單字母 span(113 有一題是紅字),單選區與複選區的欄位 x 差約 5pt,所以解析器用「分群、每群 ≥5」而不是單一眾數;依同頁 y 對回題號列,50/50 全在 2pt 內。
  - 114:**沒有答案**(見第 2 節)。
- **K-type 對照表四種寫法**:108 卷首共用表 + 個別 `Answers: (A) 1+2 …`(有的沒空格 `(B)2+3+4+5(C)…`);109/111/112 `A. (1)(2)(3)……..Are Correct` / `(1)+(3)` / `(1),(3)`;110 `(A) 123 (B) 13 (C) 24 (D) 4 (E) 1234`;113/114 `(1)(2)(3) Are Correct, Please Choose (A)` / `(1)(3), Please Choose (A)`。全部標準化成 `(1)(2)(3)`。
- **頁首雜訊**:每頁重印 `Ⅰ、單選題` / `II、複選題` + `題號 題目 答案`;113 的複選區表頭是直排的「題/號」「答/案」,被 PyMuPDF 拆成單字 span;108 複選區每頁都重印整張 `IF: (1)(2)(3)……Are Correct, Please Choose (A)` 共用表(5 行),跟 113/114 每題自帶的對照句長得一樣,只能靠「緊接在段落標題之後、以 `IF:` 開頭」來區分。沒有頁碼。
- **PyMuPDF 的三個坑**(都實際踩到):(1) 預設 `TEXT_MEDIABOX_CLIP` 會把超出 mediabox 右緣的字丟掉 —— 113-24、113-44、112-49 有整段尾巴消失(`allogeneic` → `alloge`、`patients` → `pa`),關掉旗標才完整;(2) 字與字之間的空格常是獨立的 whitespace-only span,過濾掉就會黏字(`adaptiveimmune`、`notbeen`、`HSCTshould`);(3) Symbol 字型的希臘字母是 PUA 字元,要自己映射。
- **參考列寫法不統一**:`Ref:`、`Source:`、`來源出處：`、`(Reference: …)`、`(Thomas' … P764)`、無前綴的 `Thomas'hematopoietic …`、`ESH-EBMT Handbook …`,且常跨頁、跨兩三行(110-33 的 `(Reference: EBMT handbook 2019)` 後面還接一行完整文獻)。`source` 欄已去前綴、去外層括號、合併多行;108-32 原文多一個 `)` 也已清掉。
- 108 單選 1–27 標 `(共)`,110 在 1–26;兩年的複選 36–44/47 也標 `(共)`/`共同`。111 之後沒有這個標記。
- 108 Q40、Q41 的題號後面沒有句點(`40 (共) (B)`),題號規則要容許。
